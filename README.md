# Mongo CRUD App

A Full Stack CRUD Application built with React, Node.js, Express, and MongoDB.

## Features

- Create Posts
- View Posts
- Delete Posts
- MongoDB Database Integration
- REST API with Express
- React Frontend

## Tech Stack

- React
- Vite
- Node.js
- Express.js
- MongoDB
- Mongoose

## Installation

### Backend

```bash
npm install
npm run dev
```
